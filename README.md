# Kushagra Agrawal — Portfolio

Personal developer portfolio showcasing software engineering, AI/ML systems, and product development projects.

## Tech Stack

- **Framework:** [TanStack Start](https://tanstack.com/start) & [TanStack Router](https://tanstack.com/router)
- **UI & Components:** React 19, Tailwind CSS v4, Radix UI Primitives, Lucide Icons
- **Deployment:** Cloudflare Workers / Nitro

## Development

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
```
